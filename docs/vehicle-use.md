# Gen5W KR 통합본 사용

처음 설치한다면 [엔지니어링 모드부터 시작하는 안내](beginner-guide.md)를 먼저 읽으세요. USB 번들에서는 `docs/beginner-guide.md`에 있습니다.

비공식 프로젝트로 설치 시 시스템 파일과 설정이 변경됩니다. 설치 실패·연결 불안정·표시 오류·복구 작업이 발생할 수 있으며 정상 동작을 보증하지 않습니다. 설치와 설정은 정차 상태에서 진행하고 HUD보다 실제 도로 상황과 교통 표지를 우선하세요. 법률상 배제할 수 없는 책임을 제한하지 않습니다.

NEMESIS가 설치된 Gen5W용입니다. V039 순정 파일의 정확한 해시와 Wi-Fi 하드웨어를 검사하며, 맞지 않으면 적용을 거부합니다. V039로 업데이트해서 쓰세요. 일부 모듈(브리지·오디오)은 이전 V035 해시도 알아보지만, 블루링크 안내 숨기기와 동글형은 V039 전용이고 V035는 실차·모의 모두 주 대상이 아닙니다. 제조사 파일은 이 압축파일에 없습니다.

1. [릴리스](https://github.com/Chunwol/gen5w-kr/releases/latest)에서 먼저 점검 ZIP(`gen5w-kr-check.zip`)으로 점검해 `GEN5W-REPORT/CHECK.md`의 **받을 파일**을 확인합니다. 그다음 그 설치 ZIP(기본형 `gen5w-kr-standard.zip` 또는 동글형 `gen5w-kr-dongle.zip`)을 받아 풀고 그 **내용**을 USB 루트에 복사합니다. 순정 화면·안전 조건을 유지하고 확인 버튼이 활성화되면 순정 조건을 확인해 바로 넘깁니다.
2. 정차 상태에서 USB를 꽂고 NEMESIS의 실행 확인에서 **예**를 누릅니다. **예** 없이는 설치하지 않습니다. 정상 설치 후 한 번 재부팅합니다. 제한 복구만 수행한 경우에는 재부팅하지 않습니다.
3. iPhone에서 차량과 Bluetooth 페어링을 합니다. 이미 페어링했다면 다시 연결합니다. 무선 CarPlay 연결 요청을 허용합니다.
4. 지도 앱의 길안내를 시작하고 회전·거리·차선 표시와 음악·안내 음성을 확인합니다. 유선 CarPlay도 사용할 수 있습니다.

업데이트는 USB 루트의 `GEN5W-ACTION` 파일 첫 줄에 `update`, 이전 설치로 되돌리기는 `rollback`, 전체 제거는 `remove`, 상태 확인은 `status`를 적고 같은 실행 메뉴를 선택합니다. 그 밖에 `wired-only`(무선 설정을 순정으로 되돌리고 유선 기능만 설치), `check`(아무것도 바꾸지 않고 대상 파일이 순정인지 점검해 `GEN5W-REPORT/CHECK.md`에 기록), `diag`(아무것도 바꾸지 않고 진단 기록을 `GEN5W-REPORT/DIAG-번호.txt`로 저장)도 쓸 수 있습니다. 파일이 없으면 설치합니다. USB 루트에 `GEN5W-DEBUG-ON`이 있으면 설치가 끝날 때 `GEN5W-ACTION`을 `diag`로 바꿔 두어, 재부팅 후 같은 USB를 다시 꽂으면 설치 대신 진단 기록만 저장합니다. 다시 설치하려면 `GEN5W-ACTION`을 지우세요. 작업 후 해당 파일을 지우세요. 동글형은 내장 Wi-Fi가 있는 차에서 설치를 멈춥니다. 그래도 동글을 쓰려면 USB 루트에 확장자 없는 빈 파일 `GEN5W-FORCE-DONGLE`을 둡니다. 설치가 실패하면 자동 원복을 시도하며 실패 보고서는 기기의 `/data/nemesis/gen5w-kr-integrated/report`에 남습니다. `recovery-required`이면 백업을 지우지 말고 같은 번들로 복구하세요. 설치에 쓴 ZIP은 순정 복귀(제거)에 필요하니 보관하세요.

Wi-Fi 클라이언트는 기본 꺼짐입니다. 필요한 경우에만 USB 루트에 확장자 없는 빈 파일 `GEN5W-WIFI-CLIENT`를 만들고 설치합니다. 무선 CarPlay 사용에 필수인 설정은 아닙니다. **주의:** 이 파일은 벽돌이 났던 V039 차량에 추가돼 있던 설정입니다(원인은 확정되지 않음). 부팅 중 Wi-Fi 클라이언트를 켜는 경로를 열기 때문에, 꼭 필요하지 않으면 만들지 마세요.

업데이트나 원복 과정에서 앱 설정이 초기화될 수 있습니다. 기능별 확인 범위는 [검증 안내](validation.md)를 참고하세요.

작업 후 USB의 **GEN5W-REPORT/RESULT.html**에서 기능별 결과를 확인할 수 있습니다. 다른 차종·펌웨어의 실패는 **ISSUE.md**를 검토 후 지원 요청에 첨부하세요. 이전 버전에서 업데이트할 때는 이전 버전이 먼저 순정 파일을 되돌린 뒤 새 버전을 설치합니다.

## 시동 안내가 자동으로 닫히지 않을 때

NEMESIS의 **Gen5W KR diagnostic log collector**를 실행하면 USB에 `GEN5WKR_PROBE_날짜-시간` 폴더가 생깁니다. 기본 수집에는 순정 `ConsentScreen` 시스템 로그와 타이머 판정 로그가 포함됩니다. 더 자세한 로그가 필요하면 USB 루트에 빈 `GEN5W-DEBUG-ON` 파일을 만든 뒤 다시 실행하세요. `DEBUG.txt`에는 logcat 버퍼와 Bluetooth·Wi-Fi 상태 등 확장 정보가 저장됩니다. 끄려면 `GEN5W-DEBUG-ON`을 지우거나 `GEN5W-DEBUG-OFF` 파일을 만드세요. 상세 로그에는 휴대폰·차량 식별정보가 포함될 수 있으니 이슈에 올리기 전에 열어 보고 가리세요.

## opt-in USB 주행 진단 로그

통합 설치본의 `gen5w.kr.drivelog` 서비스는 부팅 완료 후 USB 루트에 빈 `GEN5W-DEBUG-ON` 파일이 있고 `GEN5W-DEBUG-OFF`가 없을 때에만 숫자형 HUD·연결 이벤트를 기록합니다. USB가 `/storage/usb0`에 실제로 마운트되어 있고(Android 4.4의 FUSE 보기라면 그 뒤의 `/mnt/media_rw` 마운트) USB 장치임을 확인할 수 있어야 합니다. 기록하지 못하면 그 이유가 서비스 로그에 한 줄로 남고 `diag` 진단에 포함됩니다. USB 루트의 `GEN5W-DRIVELOG/`에 1 MiB 세그먼트 최대 32개를 순환 기록하며 여유 공간이 64 MiB 아래로 내려가면 멈춥니다. 일주일 보존을 보장하지 않습니다. 중단하려면 DEBUG-ON을 제거하거나 DEBUG-OFF를 추가하고 USB를 안전하게 분리하세요. 기록 항목과 경로 추론 가능성은 [주행 로그 범위와 한계](drive-log.md)를 확인하세요.

## 무선 미지원 차량

설치기가 처음에 자동 판별합니다. 무선 장치를 확인하지 못하면 새 설치는 유선 기능으로 진행합니다. 이미 설치한 무선 설정과 복구 기록이 정상이고 장치 확인만 불확실한 경우에는 기존 무선 설정을 유지합니다. 기록이 손상됐으면 설치를 중단합니다. 결과는 `GEN5W-REPORT/RESULT.html`에서 확인하세요.

내장 Wi-Fi 모듈이 없는 차량은 USB Wi-Fi 동글형을 사용할 수 있습니다. 동글형은 배포 중이지만 실차 동작은 아직 확인하지 않았고, 지원 동글(ath9k_htc)만 동작합니다.

## 핫스팟과 CarPlay 무선 연결

일반 핫스팟과 CarPlay는 접속 정보를 따로 사용하지만 Wi-Fi 장치 하나를 공유합니다. 두 AP가 동시에 켜지는 기능은 아닙니다. CarPlay 연결 시 일반 핫스팟이 중단될 수 있습니다.

시스템 파일(`services.odex`)은 바꾸지 않습니다. 무선 bridge는 순정 PhoneProjection 연결을 요청하고 핫스팟 SSID·암호를 직접 수정하지 않습니다. 순정 경로가 휴대폰과 차량의 접속 정보를 실제로 맞추는지는 실차 확인 전입니다. 예전에 겪은 Wi-Fi 이름 불일치가 해결됐다고 단정할 수 없으며, 설정값을 임의로 바꾸지 마세요.

초기 설치 시 Wi-Fi 서비스가 아직 준비되지 않았더라도 지원 원본 검사를 통과하면 설치를 진행합니다. 실제 연결은 재부팅 후 순정 PhoneProjection이 연결 요청을 처리할 때 시도합니다. 순정 서비스 접근이 거부되거나 접속 정보가 맞지 않으면 연결되지 않을 수 있습니다.
