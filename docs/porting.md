# 다른 차종·펌웨어 지원 추가

대상은 **한국 내수용 현대·기아·제네시스의 Android Gen5W**입니다. 수출형, 다른 브랜드와 다른 세대는 지원 대상이 아닙니다.

차량 이름이나 V035/V039라는 짧은 버전 이름만으로 지원을 판정하지 않습니다. 설치기는 실제 하드웨어·기능·API와 원본 파일 전체 해시를 확인합니다. 같은 이름의 버전이라도 파일이 다르면 새 포트입니다.

## 배포판 구성과 확인 상태

공식 배포판은 **기본형**과 **동글형** 두 가지입니다.

| 배포판 | 무선 연결 장치 | 시동 주의 안내 | 제공 상태 |
|---|---|---|---|
| **기본형 (내장 Wi-Fi)** | 차량 내장 Wi-Fi | 버튼 활성화 즉시 자동 전환 (Auto-Dismiss) | **공식 설치 ZIP 제공** |
| 동글형 (USB Wi-Fi) | USB Wi-Fi 동글 | 버튼 활성화 즉시 자동 전환 (Auto-Dismiss) | **공식 설치 ZIP 제공** (실차 미확인) |

- **기준 차량:** 개발에 사용한 2020 코나 하이브리드. V035/V039 원본 조합을 코드·PC에서 확인했습니다. 기존 실차 무선 CarPlay 연결 이력은 있으나 최신 통합본 전체와 즉시 자동 전환의 실차 확인은 남아 있습니다.
- **확인 필요:** 해당 차종·연식의 동작 결과가 등록되지 않았습니다. 지원 완료나 미지원 확정이라는 뜻이 아닙니다.
- **동글형:** 내장 Wi-Fi가 없는 차용으로 배포합니다. 지원 동글(ath9k_htc)과 V039 원본 `bcmdhd.ko`가 필요하며, 실차 동작은 확인하지 않았습니다.

## 타 차종 바이너리 레시피 (DL3HEV, EV6, NEEV, NEEV_KR)

## ccNC (Connected Car Navigation Cockpit) 플랫폼 아키텍처 비교

ccNC(ccIC, 고급형 6세대 등)는 Gen5W와 완전히 다른 차세대 인포테인먼트 아키텍처를 채택하고 있습니다.

| 항목 | 표준형 Gen5W (본 프로젝트 대상) | ccNC (Connected Car Navigation Cockpit) |
|---|---|---|
| **기반 OS** | Android 4.4.2 KitKat (32-bit ARMv7) | Android Automotive OS (AAOS) 10/12 (64-bit ARMv8) |
| **시스템 아키텍처** | 단일 AP (Telechips TCC893x/897x) | 하이퍼바이저(QNX Hypervisor) 기반 도메인 분리 (AP: NVIDIA / Samsung Exynos Auto) |
| **계기판 통신 방식** | 독점 IPC (`NavigationCluster.jar`) + MNSOFT 네이티브 후킹 | Google Automotive 표준 `CarNavigationStatusService` 및 `ClusterHomeService` |
| **Android Auto HUD** | 순정 비활성화 상태 (GPM step 999 차단) → **바이너리 패치 필수** | OS 레벨 공식 지원 (차량 펌웨어 설정 및 구글 공식 프로토콜 탑재) |
| **CarPlay HUD** | iAP2 RouteGuidance capability 언락 필요 | 무선 프로젝션 및 계기판/HUD 표출 기본 순정 탑재 |

> [!NOTE]
> ccNC 탑재 차량은 본 프로젝트의 Dalvik ODEX 패치나 32-bit KitKat 바이너리 패처의 적용 대상이 아니며, 이미 제조사 및 구글의 최신 표준 규격으로 동작합니다.

## USB Wi-Fi 외장 동글 지원 아키텍처 (동글형 배포판)

내장 Wi-Fi 모듈이 탑재되지 않은 Gen5W 기본 사양 트림을 위해 USB 외장 Wi-Fi 동글 배포판이 지원됩니다.

1. **지원 칩셋 및 드라이버**:
   - Realtek RTL8188EU (`8188eu.ko`)
   - Realtek RTL8821CU (`8821cu.ko`)
   - Atheros AR9271 (`ath9k_htc.ko` + `htc_9271.fw`)
2. **동작 방식**:
   - 차량 부팅 시 `tools/usb-wifi/package/bin/gen5w-dongle-load`가 USB 버스를 스캔하여 동글 식별(`0cf3:9271`, `0bda:8179`, `0bda:c811` 등).
   - 순정 `libhardware_legacy.so`는 그대로 두고, 순정이 올리는 `/system/wifi/bcmdhd.ko` 자리에 대리 모듈을 둬서 동글의 wlan0을 순정 Wi-Fi 경로로 씀(내장 Wi-Fi 없는 차용).
   - 빌드 시 `--variant dongle` 옵션을 지정하면 동글 런타임이 포함된 `gen5w.kr.dongle.zip` 패키지가 통합 USB 번들에 포함되어 배포됩니다.

## 차종 추가 요청

현대의 아반떼·쏘나타·투싼·싼타페·팰리세이드·아이오닉 5, 기아의 K5·니로·스포티지·쏘렌토·EV6 및 제네시스의 해당 Gen5W 차량도 지원 요청을 받습니다. 이 목록은 요청 대상이며 모든 연식·트림의 지원 완료 목록은 아닙니다. 각 차량에 한국 내수용 Android Gen5W가 탑재되어 있어야 합니다.

설치기는 차종 이름 대신 실제 하드웨어·API·파일을 확인하므로, 등록된 원본 조합과 같다면 별도 차종 선택 없이 진행합니다. 다른 조합은 원본을 강제로 수정하지 않고 로그에 실패 항목을 남깁니다.

기능 선언과 consent 같은 모듈은 차종 목록보다 감지를 우선합니다. audio와 bridge는 정확한 바이너리 식별을 요구합니다. HUD는 순정 iAP2/NavigationCluster API와 route capability가 필요합니다. 새로운 차량도 이 조건을 각각 확인해야 합니다.

**내장 Wi-Fi 모듈이 없는 차량은 USB Wi-Fi 동글형을 사용할 수 있습니다.** 동글형은 배포 중이지만 실차 동작은 아직 확인하지 않았습니다. 차량 커널 드라이버·순정 Wi-Fi 서비스·핫스팟 기능과 호환되는 동글이 필요하며, 아무 동글이나 연결된다고 보장하지 않습니다. 내장 모듈이 꺼져 있거나 드라이버가 응답하지 않는 상태는 실제 부재와 구분합니다.

다른 차종이나 펌웨어에서 설치가 실패하면 USB의 `GEN5W-REPORT/ISSUE.md`를 검토한 뒤 [차량 지원 요청](https://github.com/Chunwol/gen5w-kr/issues/new/choose)에 첨부하세요. 제조사 파일 자체는 첨부하지 않습니다.

## 포트 절차

1. 지원 이슈에 모델·연식·지역·정확한 펌웨어·필요 모듈을 적습니다. 제조사 파일과 개인 자료는 제출하지 않습니다.
2. 소유자가 합법적으로 확보한 원본을 개인 환경에서 분석합니다. 차량에서 원본을 꺼낼 때는 [읽기 전용 원본 수집](stock-dump.md)을 사용합니다. 다른 프로젝트 코드·패치 바이트는 사용하지 않습니다. 공개 검토에는 파일 경로, 전체 SHA256, 필요한 ABI·상수·시그니처 사실과 자체 작성 코드만 사용합니다.
3. 무선 설정은 `packages/wireless-enable/scripts/common.sh`의 기능·featurexml 감지와 순정 PhoneProjection API 접근을 확인하고, HUD는 `packages/core/scripts/pre.sh`의 API/route 조건을 확인합니다. SSID·암호 일치 여부는 실차 확인이 필요하며 알 수 없는 조건은 우회하지 않습니다.
4. bridge의 무선 요청 경로는 V039 PhoneProjection API를 반사 호출하며, 자체 RFCOMM·iAP2·AP 경로를 실행하지 않습니다. DiPO/GPM 패치는 별도 기능으로 분리해 원본 메타데이터·APK/ODEX 쌍·의존성·GC맵·체크섬과 변경 범위를 대조합니다.
5. audio는 `tools/audio`의 자체 형식 알림과 원본/변환기 프로필, `packages/audio-format/scripts`의 버전 선택을 확장합니다. 다른 차종에 코나 오프셋을 그대로 적용하지 않습니다.
6. 등록/교차 버전 거부·재설치·부분 실패·제거 시 원본 동일성·데이터 초기화 후 복구 사례를 기존 tests에 추가합니다. 제조사 바이트 대신 합성 입력을 사용하며, 전체 빌드와 검증은 기존 CI에서 수행합니다.
7. 이 문서의 지원 표에 정확한 원본 조합과 확인 범위를 적어 지원 요청에 남깁니다. CI 성공을 실차 성공으로 표시하지 않습니다. 실제 차량 확인 결과는 이후 별도 기록합니다.

현재 런타임 버전 선택은 명시적 허용 목록입니다. JSON 하나를 추가하는 것만으로 지원되지 않으며 build/helper/설치/복구 경로를 함께 갱신해야 합니다. 모든 차종을 임의로 자동 허용하는 옵션은 제공하지 않습니다.
